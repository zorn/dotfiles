# Contributing

## Skills

A change under `claude/skills/` is held to [`writing-skills`](claude/skills/writing-skills/SKILL.md): check it against every failure mode that skill lists, read from [its glossary](claude/skills/writing-skills/reference/glossary.md) rather than from the names alone. A skill that reads well can still fail one — an unreachable section, a step with no completion criterion, a negation — and those are what review has missed before.
